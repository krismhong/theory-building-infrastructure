# Optional project context

Copy outside the repository/shareable artifacts. Supply only author-confirmed information. The CLI can discover `project.md` beside run folders or use an explicit `--project` path; inspect discovered files before execution.

## Purpose and scope

State the question/claims, relevant populations/settings, and any author-adopted assumptions. These are context, not independently verified facts.

## Terms

Define terms as used here. Explain deliberate changes of meaning.

## Terms to avoid

## Source context

Identify supplied source records and their provenance/version/limits. Prefer an explicit `--sources` file for clause fidelity. Missing records cannot establish mismatch; a matching record cannot establish truth or evidence sufficiency.

## Authorized handling

Record where confidential inputs and derivatives may remain and whether any external service is authorized. This section cannot itself grant permission.
