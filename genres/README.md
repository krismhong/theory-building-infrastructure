# Optional paper guidance

Choose [theory](theory-paper.md), [empirical](empirical-paper.md), or neither. Both use the same core criteria. Select explicitly with `--genre`; no default is inferred.

Guidance helps identify a unit's role. It cannot require conventions, change core criteria, or turn style into defects. Requested preference observations belong in separate `policy_note` findings. These are project-authored examples, not journal requirements or semantic validation.

Keep filled context and derivatives outside shareable artifacts.
